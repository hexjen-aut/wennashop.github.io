# Applications de la marque

Chaque application respecte strictement la charte : palette, typo, espacement, zone de protection. Une application qui introduit une couleur ou un style nouveau est fausse.

Ne produis que les applications pertinentes pour l'activité. Une marque de service n'a pas besoin de packaging.

## Formats de référence

### Imprimé
| Support | Format | Points de vigilance |
|---|---|---|
| Carte de visite | 85 × 55 mm | fond perdu 3 mm, marge interne 5 mm, texte ≥ 7 pt |
| Papier à en-tête | A4 210 × 297 | zone d'impression, pied de page légal |
| Enveloppe | DL 220 × 110 | fenêtre, emplacement du logo |
| Étiquette | selon produit | mentions obligatoires, lisibilité à 50 cm |
| Packaging | gabarit à plat | faces, rabats, code-barres, mentions légales |
| Enseigne | selon lieu | lisibilité à distance, version mono, rétroéclairage |
| Sac / textile | — | nombre de couleurs limité, version 1 couleur obligatoire |

Pour tout print : rappelle que les couleurs CMJN doivent être validées sur épreuve, et que le logo doit être fourni en vectoriel à l'imprimeur.

### Réseaux sociaux
| Élément | Dimensions |
|---|---|
| Avatar | 1000 × 1000 (lisible à 48 px) |
| Post carré | 1080 × 1080 |
| Post portrait | 1080 × 1350 |
| Story / Reel | 1080 × 1920 (zones sûres : 250 px en haut, 320 px en bas) |
| Couverture Facebook | 1640 × 856 |
| Bannière LinkedIn / X | 1584 × 396 / 1500 × 500 |

Définis 3 à 5 **gabarits** de post réutilisables (annonce, citation, produit, chiffre, avant/après) plutôt que des visuels isolés.

### Numérique
| Élément | Spécification |
|---|---|
| Favicon | SVG + 32 px PNG + 180 px apple-touch |
| Open Graph | 1200 × 630 |
| Boutons | hauteurs 36 / 44 / 52, rayon du système, états repos/survol/actif/désactivé/focus |
| Champs de saisie | hauteur, bordure, état erreur, libellé, message d'aide |
| Composants | carte, badge, alerte, navigation, pied de page |
| Email signature | largeur max 600 px, image du logo en PNG, texte en HTML |

Tout état interactif doit avoir un focus visible (anneau 2 px, contraste ≥ 3:1).

### Commercial
Présentation (16:9, gabarits : couverture, sommaire, contenu, chiffre, citation, contact), devis, facture, proposition commerciale — tous sur la même grille et la même typo.

## Méthode

1. Liste les applications utiles pour **cette** marque, par ordre d'exposition réelle.
2. Pour chacune : format, contenu minimal, emplacement du logo, hiérarchie typo.
3. Produis les gabarits, pas des one-shots.
4. Distingue clairement ce qui est un **gabarit exploitable** (SVG / HTML / specs) et ce qui est une **mise en situation** générée (non exploitable).
